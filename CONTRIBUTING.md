# Contributing to Plumblint

External contributions are not currently being accepted.

You may study, run, modify, fork, and share the software for noncommercial
purposes under the terms of `LICENSE` (PolyForm Noncommercial 1.0.0).

Pull requests will remain closed until the project has a legally reviewed
Contributor License Agreement and a trusted process for recording acceptance.
Opening an issue does not transfer copyright or grant the project a licence to
use contributed code. Please do not submit patches or code in issues while
contributions are closed.

When contributions open, this document will be replaced with the applicable
agreement and submission process.
